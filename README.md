# Описание проекта: LLM-Based Modeling of Economic Narratives

## Общее описание

Проект посвящён автоматическому выявлению **экономических нарративов** в русскоязычных новостях Telegram - постов, которые не просто сообщают факт, а формируют упрощённую, эмоционально заряженную интерпретацию экономического события с потенциалом массового распространения. Такие нарративы важны для мониторинга информационного поля: пропущенный зарождающийся нарратив может привести к запоздалой реакции на общественно значимый инфоповод.

В основе исследования лежит корпус **Economic Telegram News Corpus 2025** - более 31 тыс. экономических постов из 7 крупных Telegram-каналов (январь 2024 - сентябрь 2025), а также экспертный **Golden Set** из 500 размеченных сообщений (Cohen's κ = 0.794 между аннотаторами). Для каждого поста определены бинарная метка наличия нарратива, сила нарратива, экономический эффект, информационный резонанс и тема.

Ключевая гипотеза проекта: качество LLM-классификации повышается, если модель видит не только текст поста, но и **временной контекст** — что уже известно по теме в окне до даты публикации. Для этого разработан пайплайн **Temporal RAG** (Retrieval-Augmented Generation с учётом времени): гибридный поиск BM25 + dense embeddings (E5), fusion через RRF, временная маска без «утечки из будущего», дедупликация репостов и LLM-judge фильтрация релевантности.

Проведён масштабный бенчмарк: несколько LLM-аннотаторов (`gpt-oss`, `qwen3-vl`, `gemma3` и др.) размечают посты в режимах без контекста и с тремя вариантами temporal-контекста. Результаты сравниваются с Golden Set по F1, F2, precision, recall и Cohen's kappa; дополнительно применяется слой **LLM-as-Judge** для оценки устойчивости ранжирования моделей.

Параллельно исследовалась альтернативная ветка - **графовые признаки** распространения новостей (семантические связи между сообщениями, PageRank каналов, доля «вирусных» соседей). Эта гипотеза не дала прироста и сохранена в репозитории как архивный эксперимент (`narratives_graph/`).

Итоговый артефакт - воспроизводимый end-to-end pipeline (`end_to_end_inference/`): от исторического корпуса и retrieval-индекса до LLM-разметки новых постов с 30-дневным контекстом. Датасеты опубликованы на Hugging Face; код структурирован по этапам: сбор данных, retrieval, разметка, бенчмарки, inference.

## Проблематика

Экономические новости в Telegram распространяются быстро, часто в виде репостов и перефразировок одного инфоповода. Для аналитика или регулятора важно отличать:

- обычную информационную заметку;
- пост, который становится **нарративом**  упрощённой рамкой восприятия с эмоциональным и поведенческим потенциалом.

Классические подходы (только текст поста, только метрики виральности) дают неполную картину: текст без контекста не показывает, новый ли это инфоповод или продолжение волны; метрики реакций запаздывают и не объясняют смысловую роль сообщения.

Дополнительные сложности:

- **временная утечка** — при построении контекста нельзя использовать будущие документы относительно даты поста;
- **масштаб корпуса** — миллионы наблюдений реакций и сотни тысяч сообщений;
- **субъективность разметки** — нужен согласованный экспертный эталон и метрики согласия;
- **разнородность LLM** — разные модели по-разному интерпретируют рубрику нарратива.

## Постановка задачи

**Основная задача:** по тексту Telegram-поста, теме и дате публикации определить, является ли сообщение экономическим нарративом, и оценить сопутствующие параметры:

| Поле | Смысл |
|---|---|
| `economic_narrative` | Да/нет — наличие нарратива |
| `narrative_strength` | Сила эмоционального фрейминга (1–3) |
| `economic_effect` | Направление и величина экономического эффекта (−2…+2) |
| `information_resonance` | Потенциал массового резонанса (1–3) |
| `topic_agreement` | Соответствие заданной теме (1–3) |

**Вспомогательные задачи:**

1. Построить leakage-safe Temporal RAG для 30-дневного окна контекста.
2. Сравнить zero-shot LLM-разметку и разметку с temporal-контекстом.
3. Оценить несколько open-weight / cloud LLM на Golden Set.
4. Проверить гипотезу о пользе графовых и структурных признаков (отдельный эксперимент).
5. Собрать переносимый inference-pipeline для разметки новых постов.

**Критерии успеха:** рост F1/F2 и recall относительно baseline без контекста; согласие с экспертами (kappa); воспроизводимость пайплайна.

## Описание технического решения

Архитектура проекта модульная:

```
Корпус (hf_datasets/)
    ↓
Temporal RAG (temporal_retrieve_virality_signals/)
    ↓
LLM-разметка (annotation/)
    ↓
Метрики (benchmarks/)  +  LLM-as-Judge (llm_as_judge/)
    ↓
End-to-end inference (end_to_end_inference/)
```

### 1. Данные

- **Economic Telegram News Corpus 2025** — 31 292 поста, 9 экономических тем, скор `viral_final`.
- **Golden Set** — 500 постов, экспертная разметка, предвычисленный `llm_context` и JSON-фичи диффузии.

### 2. Temporal RAG

Offline-индексация: BM25 + E5 embeddings + FAISS. Online-запрос:

- temporal masking (`doc_date ≤ anchor_date`);
- hybrid retrieval (dense + BM25 → RRF);
- time bonus для свежих документов;
- dedup/clustering репостов;
- LLM-judge (релевантность 0/1/2);
- сборка hot-window контекста + суммаризация.

### 3. LLM-аннотация

Скрипты `multi_model_annotation.py` и `remarkup_qwen3_context.py` формируют промпт с рубрикой нарратива и парсят JSON-ответ. Варианты контекста:

- `without_context`;
- `llm_context` — текстовая 30-дневная хронология;
- `llm_context_features` — только структурные фичи диффузии;
- `llm_context_features_full` — текст + фичи.

### 4. Оценка качества

`benchmarks/` считает F1, F2, precision, recall, kappa. `llm_as_judge/` — попарные сравнения, win-rate, ELO-ранжирование моделей.

### 5. End-to-end inference

Docker-упаковка, HTTP retrieval service, CLI-пайплайн: virality → индекс → контекст → LLM → таблица с разметкой.

### 6. Архивный эксперимент: граф (`narratives_graph/`)

Семантический граф message–message (BoW → SVD → cosine), признаки без GNN, ablation в LLM-промпте. **Не вошёл в production-пайплайн.**

## Полученные результаты

### Бенчмарк LLM-разметки (Golden Set, бинарный `economic_narrative`)

| Контекст | N | F1 | F2 | Precision | Recall | Kappa |
|---|---:|---:|---:|---:|---:|---:|
| Без контекста | 500 | 0.667 | 0.697 | 0.621 | 0.719 | 0.473 |
| `llm_context` | 100 | **0.775** | **0.852** | 0.674 | **0.912** | **0.631** |
| `llm_context_features` | 100 | 0.694 | 0.718 | 0.658 | 0.735 | 0.523 |
| `llm_context_features_full` | 100 | 0.722 | 0.747 | 0.684 | 0.765 | 0.567 |

**Выводы:**

- Текстовый temporal-контекст даёт наибольший прирост, особенно **recall** (0.719 → 0.912) и **F2** - важно для мониторинга, где пропуск нарратива дороже ложной тревоги.
- Структурные фичи без текста слабее полного контекста.
- Графовый эксперимент: F1 без графа (0.531) ≥ любой конфигурации с графовыми признаками; AUC LogReg на графе ≈ 0.56.

## Дальнейшие планы по развитию

1. **Масштабирование разметки** - прогон `llm_context` на полном Golden Set (500 постов) и всём корпусе с контролем стоимости API.
2. **Калибровка порогов** - оптимизация F2/recall под сценарий раннего предупреждения.
3. **Улучшение retrieval** - эксперименты с embedders, RRF-параметрами, channel boost; A/B на goldenset.
4. **Production-мониторинг** - потоковая обработка новых постов, алерты по всплескам нарративов в теме.
5. **Объединение сигналов** - текстовый Temporal RAG как основной канал; графовые/структурные фичи — только как дополнительный фильтр после валидации.
6. **Расширение рубрики** - мультиклассовые темы, связь нарратива с направлением экономического эффекта.
